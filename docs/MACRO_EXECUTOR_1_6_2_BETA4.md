# 1.6.2-beta.4：宏执行循环与主界面解耦

日期：2026-11-06。基线：beta.3，`545cd689a94c161c0b10eddb8d51b53ce9d45c12`。
生产与测试冻结：`6c30df33640442c804cff25b8ec2ecc439c0047d`。
本轮仅调整执行边界和重复分配，无新增功能、依赖、配置字段、线程或定时器。

## 实现与维护边界

`MacroExecutor` 负责步骤循环、执行次数、单步推进、输入输出、按住状态和循环节流。
它直接使用原有 `MacroRunCoordinator`、`OutputOwnershipManager` 和每次运行的准备计划，
不引用 Forms、控件、窗口句柄或 UI 派发。运行私有的 `MacroExecutionContext` 保存有效的
单步/循环模式、名称和按住状态；后续编辑不会改变已经启动的运行。

六个明确的环境方法连接现有策略：触发释放、编辑保护、可中断等待、物理危险快捷键、
单步推进和状态报告。`MainForm.Execution.cs` 是宿主适配层，继续调用原来的保护方法，
并负责界面文案。主窗体的工作入口只保留调用与异常/finally 收尾；原文件减少约 400 行。
实际执行器可在没有主窗口和消息循环的控制台中验证。

运行登记、停止信号、最终来源释放、句柄销毁和全局输出故障恢复仍由原宿主负责，
保持原有清理顺序。编辑/物理状态策略还属于宿主，条件与启动逻辑也未迁移。
本轮没有替换调度器、轮询频率、输入/输出后端或停止入口。

执行器的按住字典改为引用本次运行准备好的只读输入，去掉重复 Clone；所有权管理和
诊断快照仍复制自己的数据。独立测试覆盖后端、诊断快照和配置修改，确认这些修改
不能反向污染缓存或其他运行。

配置读写与 XML 模型未变；沿用既有配置加载、保存和重新打开路径。

## 测量方式

同机旧版/新版驱动编译全部冻结生产源码，用私有桌面的真实 `MainForm.MacroWorker`
执行混合键盘、鼠标侧键、滚轮、摇杆和扳机步骤。每样本 2,000 次重复、20,000 步，
预热后记录当前线程分配、耗时、完整输出字段校验和及最终来源数，不强制 GC。
输出使用观察器；包内另附测量驱动与日志。

最终冻结后按新版→旧版的相反顺序复测，每 20,000 步的分配中位数由
22,557,768 B 降到 22,173,816 B，减少 383,952 B，约 1.7%。耗时中位数
51.728 / 51.106 ms，表现接近；首轮耗时差异未作为提速结论。两版均为
12,000 个按下边沿、8,000 个释放边沿，完整字段/顺序校验和
`15508316335096831171` 相同，最终来源为 0。滚轮是即时边沿，按下/释放数量本身无需相等。
这一测量包含执行和所有权，不包含真实驱动输出、用户等待或整机 CPU/功耗。

## 最终验收

冻结源码的执行器控制台检查 339 项通过，覆盖有限/无限/单步、触发释放、开始延时、
每步编辑保护、等待/取消边界、同源 Down/Press/Up、跨来源重叠、摇杆状态更新、输入
副本隔离和异常后的调用方清理。主窗体的实际保护与故障清理另由 UI 安全 117 项覆盖。
协调 55 项、输出所有权 303,716 项、高级触发 163 项、输入管线 24 项和 SDL 断开重连
100 轮通过。150 ms 长按阈值的实际派发样本：普通界面 162 ms，界面阻塞 400 ms 时
157 ms，输出发生在界面恢复之前。时序 15 项通过，零等待滚轮仍受节流且可以停止。
产品/旧配置 802 项和创建、编辑、保存到运行流程 142 项通过。

一次最终持续运行 60.1 秒、437 轮、219 次长按、21 个界面阻塞样本通过。
键盘按下/释放均为 2,346，结束后输出来源与按住状态均为 0；共创建 2 个宏工作线程，
GDI 26→26、USER 30→30，无强制 GC。该结果为本轮冻结源码重新执行，未沿用 beta.3
的旧持续样本，也未重复十分钟长测。

结果记录在本轮 `verification.json`、按范围选择日志和持续运行报告中。普通界面检查
全部在不切换的私有桌面执行，控制台检查不创建主窗口。

本轮选择 17 项，全部通过：11 套相关回归、持续运行、创建运行流程、三个设置检查和
验证流程。主执行源码与生产清单改变，使这些项目的声明输入指纹改变，因此本轮
17 项均为新执行，未将旧结果记为新结果；未受影响的 OBS、隔离断网和更新路径不重复。
新的源码/断言/依赖指纹及日志哈希已登记，后续可以复用仍匹配的结果。没有运行
无条件 44 套全量验收。

中英文设置在 100%～200% 缩放通过 8,784 项 / 8 窗口，实际 144 DPI 通过
2,188 项 / 2 窗口；成品设置检查覆盖紧凑/默认窗口、旧 XML 默认值和保存的手柄状态。
唯一生产清单 71 文件 / 448 项、验证选择/失效/复用规则 32 项通过。

真实 ViGEm/XInput 紧急停止检查 11 项通过，覆盖全局清理、禁止立即重触发、显式恢复
和最终归零。前置检查最初因现有实例运行而暂停；用户正常关闭后按原规则通过，
没有绕过前置检查。该路线不运行键鼠 SendInput 场景。

x64/x86 最终成品均通过架构/元数据/资源校验，原生缓存提取/复用/损坏修复，
