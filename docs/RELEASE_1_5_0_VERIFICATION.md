## 版本与升级范围

本版从已验收的 beta.15 提升为正式版，保留宏执行、输出所有权和窗口/无边框准星代码。
另按用户要求修复软件内更新后的旧文件名：成功安装后统一使用 **InputStitch.exe**。
改名、替换或发起启动失败时恢复原程序，保留程序及配置备份；遇到另一个同名程序则停止而不覆盖。
同步常见桌面/开始菜单中原有快捷方式的目标，保留自定义名称、参数与工作目录；其他位置的快捷方式可手动改指向。

1.4.3 与新版都读取 `%APPDATA%\InputStitch\config.xml`，配置格式均为 3。
老用户无需导出、导入或重新设置宏。新增选项使用兼容默认值，准星默认关闭。
使用[原始 1.4.3 EXE 生成的配置样本](https://github.com/ZhiHanyu-H57/InputStitch/blob/v1.5.0/tests/fixtures/README.md)，
验证实际编辑器加载、保存、再次打开，每个原始 XML 叶节点值均保留，并保留原文件备份。
