# 1.5.2-beta.1：鼠标、录制与批量时间编辑

本轮针对用户反馈修复，正式下载和稳定更新仍为 1.5.1。
不改配置格式、输入发送器、宏调度、目标窗口策略或现有停止机制。
验收完成：2026-10-23。代码提交：`132069ac9ab43a43cdb528b9e687ebafa46c1ef9`。

## 修复内容

- 键盘图原来只显示键盘、载入时过滤鼠标，并把确认的输入固定写成键盘类型。
  选择器现提供键盘和鼠标两个页签，保留鼠标输入类型及 Ctrl 等组合，重新打开可继续编辑。
- 步骤编辑明确区分键盘、鼠标、虚拟手柄。鼠标采用 imagegen 生成的实物质感底图；
  左右键、中键、两个侧键可直接点图选择，滚轮方向可点旁边标注选择。
  侧键使用后退/前进名称并保留 X1/X2 标识。白色外壳搭配深灰滚轮和侧键，内嵌图片约 38.5 KiB，保留透明边缘，
  首次显示时解码一次并共用；没有新增运行依赖。素材和完整生成提示见 assets/README.md。
- 修复开始录制时未结束单键录入的状态冲突；旧录入状态曾优先取走录制输入。
  录制提示明确可切到任意程序，不需要锁定目标窗口。自动切换方案和 UI 运行目标保持原有用途。
  录制仍忽略软件自身界面点击和自身注入的输入，保留紧急停止优先级。
- “批量间隔”改为“批量时间”。支持所选步骤/全部步骤，分别勾选按住时长、等待时长，
  等待支持固定值与随机范围。多选步骤点击“编辑”直接进入此窗口，修改可一次撤销/重做。
  按住时长适用于自动松开的“按一下”；独立按下、松开及滚轮步骤通过等待时长调整节奏。

## 自动化验收范围

按实际改动选择检查，没有以人工试用作为前提，也不把定向验证称作全套正式发布验收。

- `RecordingEditingTests`：鼠标图/真实回调解码、组合与类型往返；录制前台边界使用独立进程的真实窗口，
  无目标及失效目标；单键录入冲突、自身界面点击排除；批量范围、固定/随机、无效范围、
  编辑入口、撤销/重做和保存重开。默认显式提供前台窗口边界以适应后台/CI；`--recording-native`
  另覆盖实际前台切换。原生鼠标数据由测试构造，Input Lab 单独覆盖真实输出。
  图片另有比例、点击缩放、右键/中键引导线顺序及本机原生 DPI 像素复制检查。
- 相关回归：`KeyboardTests`、`ProductivityTests`（含旧配置迁移）、`UiSafetyTests`、
  `ModifierSafetyPolicyTests`、`OutputOwnershipTests`、`SourceManifestTests`、`ReleasePolicyTests`。
- 布局：受影响的步骤、键盘/鼠标选择和批量时间窗口，中英文、100/125/150/200% 字体缩放，
  默认尺寸、缩小、恢复及页签切换；另检查本机原生 DPI。
- 完整新手流程、独立 Input Lab 实际输出、x64/x86 打包启动与依赖提取、版本与哈希。
