下载与启动Download & launch

系统需要 .NET Framework 4.7.2 或兼容的更高版本。64 位 Windows 选择 x64，32 位 Windows 选择 x86。Requires .NET Framework 4.7.2 or a compatible later version. Choose x64 for 64-bit Windows or x86 for 32-bit Windows.

  1. 下载程序Download the program

    进入下载页，选择与你的系统对应的 EXE。Open Downloads and choose the EXE for your system.

  2. 放入常用文件夹并运行Choose a folder and launch

    把 EXE 放入你的工具文件夹，双击启动。可将文件名改为 InputStitch.exe。Place the EXE in your tools folder and double-click it. You can rename it to InputStitch.exe.

键盘、鼠标宏可直接使用。虚拟手柄输出的驱动设置见下方“手柄输入与输出”。Keyboard and mouse macros are ready to use. For virtual-controller output, see Controller input & output below.

创建第一个宏Create your first macro

下面以“按 F8 开始重复点击，再按 F8 停止”为例。This example uses F8 to start repeated left clicks, then F8 again to stop.

  1. 新建宏Create a macro

    点击左侧“＋ 新建宏”，选择“重复操作”模板，并填写名称。Click ＋ New macro on the left, choose Repeat an action and give it a name.

  2. 设置触发键Set the shortcut

    点击“触发键”，直接按 F8，或用下拉按钮打开虚拟键盘选择 F8。Click Trigger and press F8, or open the virtual keyboard with the adjacent dropdown and choose F8.

  3. 选择触发方式与循环Choose behavior and repeat

    将“触发方式”设为“按一次启动，再按停止”，勾选“无限循环”。Choose Press to start / again to stop and enable Repeat until stopped.

  4. 编辑点击步骤Edit the click action

    在“执行步骤”中设置鼠标左键，操作选择“按一下”，例如按住 25 ms、等待 120 ms。已有步骤可双击编辑。Set a left mouse-button Press action, for example with a 25 ms hold and a 120 ms delay. Double-click an existing step to edit it.

  5. 运行与停止Run and stop

    设置会自动保存。返回要操作的窗口，按 F8 开始，再按 F8 停止；也可使用底部“执行所选宏”和“全部停止”。Edits save automatically. Switch to the target window and press F8 to start, then again to stop. You can also use Run selected macro and Stop all at the bottom.

默认紧急停止：Ctrl + Shift + F12。用于停止宏、释放输出并暂停全局触发。需要恢复时，在齿轮菜单取消“暂停全局宏触发”。Default Emergency Stop: Ctrl + Shift + F12. Stops macros, releases output and pauses global triggers. Uncheck Pause global macro triggers in the gear menu to resume.

设置触发方式Choose trigger behavior

“触发键”决定用哪个输入，“触发方式”决定何时开始和停止。“时间与条件”中可调整短按、长按、双击的时间及生效窗口。Shortcut chooses the input. Trigger behavior chooses when the macro starts or stops. Timing & conditions sets short/long/double-press timing and application conditions.

触发方式Behavior使用方法How it works
按一次启动，再按停止Press to start / again to stop按一次开始，执行中再按一次停止。适合持续循环。Press once to start; press again to stop an active run. Useful for continuous repeats.
按住运行，松开停止Hold to run / release to stop触发键按着时运行，松开停止。Run while the shortcut is held; release it to stop.
按下时执行 / 松开时执行On press / On release在按下或松开的时刻执行。Run at the moment the shortcut is pressed or released.
短按 / 长按 / 双击Short / Long / Double press按所设置的时间和手势触发。Run when the configured timing and gesture are met.

单独设置的按键可与按住的 Shift 共用；明确设置的组合键优先。“屏蔽触发键/鼠标事件”可在触发时拦截最后一个按键或鼠标事件。Bare keys work while Shift is held; explicitly configured chords take priority. Block trigger input intercepts the final key or mouse event when triggered.

编辑执行步骤Edit action steps

点击“＋ 添加步骤”，选择键盘、鼠标或手柄操作。键盘按键支持实际录入和虚拟键盘两种选择方式。Click ＋ Add step and choose a keyboard, mouse or controller action. Keys can be captured from your keyboard or chosen on the virtual keyboard.

设置项Setting用途Use
按一下Press按下并在设定的时间后松开。Press, then release after the configured hold time.
按下 / 松开Down / Up分别设置按下与松开，可用于组合动作。Use separate down and up steps to build combined actions.
按住（ms）Hold (ms)动作保持的时间。How long the action stays pressed.
等待（ms）Delay (ms)此步骤结束到下一步骤之间的间隔。The wait after this step before the next one.

按 Ctrl 或 Shift 多选步骤，打开“批量时间”，可统一修改按住时长、等待时长，或同时修改两者。“单步执行”按顺序逐个执行步骤。Use Ctrl or Shift to select steps, then open Batch timing to change hold times, delays or both. Single-step runs the sequence one step at a time.

点击“录制宏”即可跨窗口记录键鼠操作。切到要操作的程序，完成后返回 InputStitch 点“停止录制”，再编辑步骤或批量修改时间。Click Record Macro to capture keyboard and mouse actions across applications. Switch to the application, perform the actions, then return to InputStitch and click Stop Recording. You can then edit steps or change their timing in batches.

设置屏幕准星Set up a screen crosshair

  1. 开启准星Enable the crosshair

    点击主界面左侧“屏幕准星…”，勾选“开启屏幕准星”和“显示准星”。Click Screen crosshair… on the left. Select Enable crosshair and Show crosshair.

  2. 选择样式并调整Choose and adjust a style

    “准星样式”可选圆点、方块、十字、圆环等。新样式“缺角方环”是四角留有缺口的正方形环；用“大小”“线宽”和“四角缺口”调整形状，再设置颜色、描边和不透明度。Choose a dot, square, cross, ring or another style. The new Corner-cut square leaves a gap at each corner. Adjust Size, Line width and Corner gap, then set colors, outline and opacity.

  3. 微调位置并保存Position and save

    选择显示器，以屏幕中央为起点调整 X/Y 偏移；需要重新居中时点“回到屏幕中央”。点击“保存准星设置”，下次启动恢复设置。默认显隐快捷键为 Ctrl + Alt + F10。Choose a display and adjust X/Y offsets from its center, or click Reset to center. Click Save crosshair to keep the settings for the next launch. The default show/hide shortcut is Ctrl + Alt + F10.

游戏请使用窗口化或无边框窗口模式。Set the game to windowed or borderless mode.

设置屏幕计时器Set up a screen timer

  1. 选好要显示的时间Choose the time display

    点击主界面左侧“计时器…”，勾选“启用计时器”和“显示计时器”。在“内容与样式”选择“分:秒.毫秒”预设，即可显示类似 01:23.456 的时间。Open Timer… on the left and select Enable timer and Show timer. In Content & style, choose Minutes:seconds.ms for a display such as 01:23.456.

  2. 设置显示位置Set the output and position

    在“显示与位置”选择“普通置顶窗口”，再选择显示器。滑块用于粗调，X/Y 数字框可逐像素微调；左上角为原点。In Output & position, choose Desktop overlay and a display. Use the sliders for rough placement and the X/Y fields for one-pixel adjustments from the top-left corner.

  3. 设置快捷键并保存Set shortcuts and save

    在“快捷键”选择控制方式，录入对应按键，点击“保存”。返回游戏后使用快捷键开始或暂停计时；也可以在设置窗口点“开始 / 暂停”和“归零”。In Hotkeys, choose a control mode and assign its keys, then Save. Use the shortcuts in the game, or the Start / pause and Reset buttons in the settings window.

调整内容和格式Edit content and formatting

  • 左侧勾选框决定是否显示该部分。选中“时”“分”“秒”“毫秒”或文字行，在右侧编辑该部分。取消勾选“时”即可隐藏小时。Checkboxes on the left control which parts appear. Select an hour, minute, second, millisecond or text row to edit it on the right. Clear Hours to hide it.
  • 按 Ctrl / Shift 多选，或点“全选”，再统一修改字体、字号、加粗、斜体、颜色、描边、字距和不透明度。“套用首项样式”可复制第一个选中部分的完整格式。Use Ctrl / Shift to select several parts, or Select all, then change their font, size, bold, italic, colors, outline, spacing or opacity together. Use first style copies the first selected part’s complete formatting.
  • 用“添加文字”加入中文、英文或标点，用箭头调整顺序；点“换行”分成多行，再到“显示与位置”调整“额外行距”。Use Add text for Chinese, English or punctuation, and the arrows to reorder parts. Click New line for multiple lines, then adjust Extra line spacing under Output & position.
  • “刷新间隔”默认为 50 毫秒，可在 16–5000 毫秒之间调整。数值越大，显示更新越少；计时精度不受影响。Refresh interval defaults to 50 ms and accepts 16–5000 ms. Larger values update the display less often without changing elapsed-time accuracy.

用 OBS 录入计时器Include the timer in OBS

普通置顶窗口适合只在自己的屏幕上查看；OBS“游戏捕获”录入 RTSS 游戏内绘制。OBS 的“显示器捕获”会录入普通置顶窗口。Use Desktop overlay to view the timer on your screen. For OBS Game Capture, use the RTSS in-game overlay. OBS Display Capture also records desktop overlays.

  1. 安装并启动 RivaTuner Statistics Server（RTSS）7.3.7+，在 RTSS Setup 中开启 Use Microsoft Detours API hooking。Install and start RivaTuner Statistics Server (RTSS) 7.3.7+ and enable Use Microsoft Detours API hooking in RTSS Setup.
  2. 在计时器“显示与位置”中选择“RTSS 游戏内绘制”。此时 X/Y 以游戏画面的左上角为原点。Choose RTSS in-game overlay under Output & position. X/Y now use the top-left of the game frame.
  3. 在 OBS“游戏捕获”的属性中开启“捕获第三方叠加层”。Enable Capture third-party overlays in the OBS Game Capture source properties.

断网与恢复Network control

  1. 选择断网范围Choose what to block

    打开主界面齿轮菜单 →“断网与恢复…”，勾选“启用网络控制快捷键”。选择“指定程序”，点“添加程序…”选择实际运行的 EXE，可添加多个；选择“整台电脑”则控制这台电脑的网络。Open the gear menu → Network control… and select Enable network hotkeys. Choose Selected applications and Add apps… to select the EXE files that run the applications; you can add several. Whole computer controls network traffic for the entire PC.

  2. 设置断开与恢复按键Assign block and restore keys

    在“范围与快捷键”分别选择“断开网络”和“恢复网络”的按键。两个按键相同时，按一次断开，再按一次恢复。点“保存”后，在要操作的窗口使用快捷键。首次断网时按 Windows 提示允许管理员授权。In Scope & hotkeys, assign Block traffic and Restore traffic. Using the same shortcut for both makes it toggle between blocking and restoring. Save, then use the shortcuts in the application. Allow the Windows administrator prompt on first use.

  3. 选择音效Choose sound cues

    在“音效”分别开关断开、恢复提示音并调整音量。可“导入…”自己的 8/16 位 PCM WAV 文件，点“试听”确认；“使用内置”恢复默认声音。In Sounds, enable or disable each cue and set its volume. Import… accepts 8/16-bit PCM WAV files. Use Preview to listen, or Use built-in to restore the default sound.

需要恢复时，按恢复快捷键，或点齿轮菜单中的“恢复网络”。紧急停止和退出 InputStitch 也会解除断网；下次启动保持联网。To reconnect, press the restore shortcut or choose Restore network from the gear menu. Emergency Stop and exiting InputStitch also remove the block. The next launch starts connected.

手柄输入与输出Controller input & output

手柄按键、扳机和摇杆可用作触发输入。需要将操作输出成手柄信号时，在设置中选择 Xbox 360 或 DualShock 4 虚拟手柄。Use controller buttons, triggers and sticks as inputs. For controller output, select a virtual Xbox 360 or DualShock 4 controller in Settings.

使用方式Use设置Setup
键盘、鼠标输出Keyboard/mouse output直接创建和运行宏。Create and run macros directly.
手柄触发键鼠操作Controller to keyboard/mouse连接手柄后，在触发键选择中录入手柄输入。Connect the controller and capture its input in the shortcut selector.
虚拟手柄输出Virtual-controller output安装 ViGEmBus，选择虚拟手柄类型并连接。Install ViGEmBus, select a virtual-controller type and connect it.

设备接管（实验性）Controller takeover (Experimental)

设备接管用于隐藏实体手柄，让目标程序接收虚拟手柄输入。该选项需要 HidHide；可在手柄相关设置中配置。Takeover hides the physical controller so the target application receives the virtual controller. It requires HidHide and is configured in the controller settings.

使用映射层Use mapping layers

映射层用于给不同用途分组。打开宏的“更多设置”，选择所属映射层；基础层始终生效，可再叠加一个命名层。Layers group macros by purpose. Open More options for a macro and choose its layer. Base stays active, with one named layer on top.

命名层可以用快捷键切换，也可设置为按住时临时生效，或根据前台窗口条件自动生效。Switch named layers with a shortcut, hold a shortcut to activate a layer temporarily, or activate one using foreground-window conditions.

更新与配置Updates & configuration

在软件设置中检查更新。更新会保留宏和设置，并在替换前备份旧程序与配置。更新后的主程序文件名为 InputStitch.exe。Check for updates in Settings. Updates keep macros and settings, backing up the program and configuration before replacement. The installed name is InputStitch.exe.

手动更新时，关闭旧程序后运行新版。1.4.3 及 1.5.x 的宏与设置会自动读取。For a manual update, close the old program and run the new EXE. Macros and settings from 1.4.3 and 1.5.x load automatically.

配置保存在 %APPDATA%\InputStitch。可通过左侧“导入与备份”导出宏或配置方案，便于备份和换电脑。Configuration is stored in %APPDATA%\InputStitch. Use Import & backup on the left to export macros or profiles for backup or another computer.

常见问题Common questions

触发键没有响应时先检查哪里？What should I check if a shortcut does not respond?

返回要操作的窗口，确认宏已启用“启用触发键”，并检查“时间与条件”中的生效范围。编辑软件界面时，输入会用于界面操作。Switch to the target window, enable the macro shortcut and check its Timing & conditions scope. While editing InputStitch, inputs are used for the interface.

如何立即停止正在运行的宏？How do I stop active macros immediately?

点击底部“全部停止”，或按默认紧急停止快捷键 Ctrl + Shift + F12。Click Stop all at the bottom, or use the default Emergency Stop: Ctrl + Shift + F12.

虚拟手柄在游戏中没有出现怎么办？The virtual controller does not appear in a game.

确认已安装 ViGEmBus，并在 InputStitch 中连接虚拟手柄。部分游戏在启动时识别设备，可以先连接虚拟手柄，再启动游戏。Install ViGEmBus and connect the virtual controller in InputStitch. Some games detect devices at startup; connect the virtual controller before launching the game.
