下载与启动Download & launch

系统需要 .NET Framework 4.7.2 或兼容的更高版本。64 位 Windows 选择 x64，32 位 Windows 选择 x86。Requires .NET Framework 4.7.2 or a compatible later version. Choose x64 for 64-bit Windows or x86 for 32-bit Windows.

  1. 下载程序Download the program

    进入下载页，选择与你的系统对应的 EXE。Open Downloads and choose the EXE for your system.

  2. 放入常用文件夹并运行Choose a folder and launch

    把 EXE 放入你的工具文件夹，双击启动。可将文件名改为 InputStitch.exe。Place the EXE in your tools folder and double-click it. You can rename it to InputStitch.exe.

键盘、鼠标宏可直接使用。虚拟手柄输出的驱动设置见下方“手柄输入与输出”。Keyboard and mouse macros are ready to use. For virtual-controller output, see Controller input & output below.

创建第一个宏Create your first macro

下面以“按 F8 开始重复点击，再按 F8 停止”为例。This example uses F8 to start repeated left clicks, then F8 again to stop.

  1. 新建宏Create a macro

    点击左侧“＋ 新建宏”，选择“重复操作”模板，并填写名称。Click ＋ New macro on the left, choose Repeat an action and give it a name.

  2. 设置触发键Set the shortcut

    点击“触发键”，直接按 F8，或用下拉按钮打开虚拟键盘选择 F8。Click Trigger and press F8, or open the virtual keyboard with the adjacent dropdown and choose F8.

  3. 选择触发方式与循环Choose behavior and repeat

    将“触发方式”设为“按一次启动，再按停止”，勾选“无限循环”。Choose Press to start / again to stop and enable Repeat until stopped.

  4. 编辑点击步骤Edit the click action

    在“执行步骤”中设置鼠标左键，操作选择“按一下”，例如按住 25 ms、等待 120 ms。已有步骤可双击编辑。Set a left mouse-button Press action, for example with a 25 ms hold and a 120 ms delay. Double-click an existing step to edit it.

  5. 运行与停止Run and stop

    设置会自动保存。返回要操作的窗口，按 F8 开始，再按 F8 停止；也可使用底部“执行所选宏”和“全部停止”。Edits save automatically. Switch to the target window and press F8 to start, then again to stop. You can also use Run selected macro and Stop all at the bottom.

默认紧急停止：Ctrl + Shift + F12。用于停止正在运行的宏并释放输出。Default Emergency Stop: Ctrl + Shift + F12. Stops active macros and releases their output.

设置触发方式Choose trigger behavior

“触发键”决定用哪个输入，“触发方式”决定何时开始和停止。“时间与条件”中可调整短按、长按、双击的时间及生效窗口。Shortcut chooses the input. Trigger behavior chooses when the macro starts or stops. Timing & conditions sets short/long/double-press timing and application conditions.

触发方式Behavior使用方法How it works
按一次启动，再按停止Press to start / again to stop按一次开始，执行中再按一次停止。适合持续循环。Press once to start; press again to stop an active run. Useful for continuous repeats.
按住运行，松开停止Hold to run / release to stop触发键按着时运行，松开停止。Run while the shortcut is held; release it to stop.
按下时执行 / 松开时执行On press / On release在按下或松开的时刻执行。Run at the moment the shortcut is pressed or released.
短按 / 长按 / 双击Short / Long / Double press按所设置的时间和手势触发。Run when the configured timing and gesture are met.

“屏蔽触发键/鼠标事件”可在触发宏时拦截最后一个触发按键或鼠标事件。Block trigger input intercepts the final shortcut key or mouse event when the macro is triggered.

编辑执行步骤Edit action steps

点击“＋ 添加步骤”，选择键盘、鼠标或手柄操作。键盘按键支持实际录入和虚拟键盘两种选择方式。Click ＋ Add step and choose a keyboard, mouse or controller action. Keys can be captured from your keyboard or chosen on the virtual keyboard.

设置项Setting用途Use
按一下Press按下并在设定的时间后松开。Press, then release after the configured hold time.
按下 / 松开Down / Up分别设置按下与松开，可用于组合动作。Use separate down and up steps to build combined actions.
按住（ms）Hold (ms)动作保持的时间。How long the action stays pressed.
等待（ms）Delay (ms)此步骤结束到下一步骤之间的间隔。The wait after this step before the next one.

选中步骤后可编辑、复制、删除或上下移动；“批量间隔”统一调整多个步骤的时间。“单步执行”按顺序逐个执行步骤。Select steps to edit, duplicate, delete or move them. Bulk timing adjusts multiple steps. Single-step runs the sequence one step at a time.

选择宏模板Choose a macro template

模板Template适用操作Suitable actions
按住控制手柄Hold a controller input按住触发键时推动虚拟摇杆或保持手柄按钮。Hold a shortcut to move a virtual stick or keep a controller button pressed.
按顺序执行Run a sequence多个键盘、鼠标或手柄动作按顺序执行。Run several keyboard, mouse or controller actions in order.

模板创建后都可以在主界面继续编辑。将鼠标侧键按住映射到 E 时，可从空白宏开始，选择“按住运行，松开停止”，并添加 E 的按键步骤。All templates remain editable. To map a held mouse side button to E, start from scratch, choose Hold to run / release to stop, and add an E key step.

设置屏幕准星Set up a screen crosshair

  1. 打开准星设置Open crosshair settings

    点击主界面左侧的“屏幕准星…”，开启绘制。Click Screen crosshair… on the left and enable the overlay.

  2. 选择外观与位置Choose appearance and position

    选择圆点、方块、十字、圆环等样式，调整大小、线宽、描边、颜色和透明度。准星默认居中，可用位置偏移进行精确微调。Choose dot, square, cross, ring or another style. Set size, line width, outline, colors and opacity. The crosshair starts centered; use offsets for precise positioning.

  3. 保存并使用快捷键Save and use the shortcut

    保存设置后，下一次开启准星时会恢复。默认使用 Ctrl + Alt + F10 显示或隐藏。Saved settings are restored when the crosshair is enabled again. The default show/hide shortcut is Ctrl + Alt + F10.

准星用于窗口化和无边框窗口。游戏使用独占全屏时，在游戏的显示设置中切换到无边框窗口。Use the crosshair in windowed or borderless mode. If a game uses exclusive fullscreen, change its display setting to borderless.

手柄输入与输出Controller input & output

手柄按键、扳机和摇杆可用作触发输入。需要将操作输出成手柄信号时，在设置中选择 Xbox 360 或 DualShock 4 虚拟手柄。Use controller buttons, triggers and sticks as inputs. For controller output, select a virtual Xbox 360 or DualShock 4 controller in Settings.

使用方式Use设置Setup
键盘、鼠标输出Keyboard/mouse output直接创建和运行宏。Create and run macros directly.
手柄触发键鼠操作Controller to keyboard/mouse连接手柄后，在触发键选择中录入手柄输入。Connect the controller and capture its input in the shortcut selector.
虚拟手柄输出Virtual-controller output安装 ViGEmBus，选择虚拟手柄类型并连接。Install ViGEmBus, select a virtual-controller type and connect it.

设备接管（实验性）Controller takeover (Experimental)

设备接管用于隐藏实体手柄，让目标程序接收虚拟手柄输入。该选项需要 HidHide；可在手柄相关设置中配置。Takeover hides the physical controller so the target application receives the virtual controller. It requires HidHide and is configured in the controller settings.

使用映射层Use mapping layers

映射层用于给不同用途分组。打开宏的“更多设置”，选择所属映射层；基础层始终生效，可再叠加一个命名层。Layers group macros by purpose. Open More options for a macro and choose its layer. Base stays active, with one named layer on top.

命名层可以用快捷键切换，也可设置为按住时临时生效，或根据前台窗口条件自动生效。Switch named layers with a shortcut, hold a shortcut to activate a layer temporarily, or activate one using foreground-window conditions.

更新与配置Updates & configuration

在软件设置中检查更新。更新会保留宏和设置，并在替换前备份旧程序与配置。更新后的主程序文件名为 InputStitch.exe。Check for updates in Settings. Updates keep macros and settings, backing up the program and configuration before replacement. The installed name is InputStitch.exe.

手动更新时，关闭旧程序后运行新版。1.4.3 和 1.5.0 的配置会自动读取。For a manual update, close the old program and run the new EXE. Settings from 1.4.3 and 1.5.0 load automatically.

配置保存在 %APPDATA%\InputStitch。可通过左侧“导入与备份”导出宏或配置方案，便于备份和换电脑。Configuration is stored in %APPDATA%\InputStitch. Use Import & backup on the left to export macros or profiles for backup or another computer.

常见问题Common questions

触发键没有响应时先检查哪里？What should I check if a shortcut does not respond?

返回要操作的窗口，确认宏已启用“启用触发键”，并检查“时间与条件”中的生效范围。编辑软件界面时，输入会用于界面操作。Switch to the target window, enable the macro shortcut and check its Timing & conditions scope. While editing InputStitch, inputs are used for the interface.

如何立即停止正在运行的宏？How do I stop active macros immediately?

点击底部“全部停止”，或按默认紧急停止快捷键 Ctrl + Shift + F12。Click Stop all at the bottom, or use the default Emergency Stop: Ctrl + Shift + F12.

虚拟手柄在游戏中没有出现怎么办？The virtual controller does not appear in a game.

确认已安装 ViGEmBus，并在 InputStitch 中连接虚拟手柄。部分游戏在启动时识别设备，可以先连接虚拟手柄，再启动游戏。Install ViGEmBus and connect the virtual controller in InputStitch. Some games detect devices at startup; connect the virtual controller before launching the game.
